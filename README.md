# Премиальный промо-сайт «Кухни на заказ под ключ» [PLACEHOLDER]

Интерактивный презентационный промо-лендинг ультрасовременного европейского уровня для фабрики/студии авторских кухонь.

---

## 🌟 Ключевые особенности и реализация

1. **Европейский дизайн и стиль**:
   - Палитра глубокого графита (`#0C0E12`, `#141820`) с благородными акцентами шампань и античного золота (`#D4AF37`, `#C8A97E`).
   - Эффекты Glassmorphism, мягкие тени, подсветки и плавная типографика (`Manrope` + `Playfair Display`).

2. **Интерактивный 5-шаговый калькулятор стоимости**:
   - **Шаг 1: Форма кухни** (Прямая, Угловая, П-образная, С островом с динамическими коэффициентами).
   - **Шаг 2: Длина гарнитура** (Интерактивный ползунок от 2.0 до 7.0 погонных метров с шагом 0.1 м).
   - **Шаг 3: Материалы фасадов** (Австрийский ЛДСП EGGER, МДФ Soft-Touch, Итальянская эмаль Milesi, Натуральный шпон дуба/массив).
   - **Шаг 4: Столешницы** (Влагостойкий HPL пластик 38 мм, Бесшовный акриловый камень Grandex, Кварцевый агломерат Caesarstone).
   - **Шаг 5: Опции комфорта** (Австрийские доводчики Blum Legrabox, Умная сенсорная LED-подсветка, Пакет встройки бытовой техники).
   - **Мгновенный пересчет**: Отображение расчетной стоимости в реальном времени с учетом акции (-15%).
   - **Интеграция с WhatsApp**: Кнопка автоматически формирует готовый детальный текст сообщения с выбранными параметрами и открывает чат.

3. **Каталог и портфолио с фильтрацией**:
   - Фильтрация по стилям: *Все*, *Современный*, *Лофт*, *Неоклассика*, *Сканди*.
   - Интерактивное модальное окно детального просмотра проекта с характеристиками, описанием и персональным расчетом.

4. **Интеграция с WhatsApp**:
   - Плавающая пульсирующая кнопка с микроанимацией в правом нижнем углу.
   - Быстрые ссылки в шапке, подвале и карточках проектов с предзаполненными UTM/текстовыми параметрами.

5. **Все обязательные блоки**:
   - Header с логотипом, телефоном, навигацией и кнопками вызова замерщика.
   - Hero-секция с сильным УТП, триггерами доверия и промо-карточкой спецпредложения.
   - Преимущества и инженерные стандарты (немецкие ЧПУ Homag, PUR-кромление, австрийский Blum, лазерный замер).
   - 5 этапов прозрачной работы со сроками.
   - Отзывы клиентов с оценками и описанием реализованных объектов.
   - Шоурум, контакты, форма быстрой записи на консультацию и вызов замерщика.
   - Полный адаптивный Footer с реквизитами и правовой информацией.

---

## 🚀 Как запустить и протестировать

Файл `index.html` полностью автономен и не требует сборщиков:
- Просто откройте `index.html` в любом браузере (Google Chrome, Safari, Edge, Firefox).
- Все стили (Tailwind CSS), шрифты (Google Fonts) и векторные иконки (Lucide Icons) подключены через CDN.

Для развертывания на хостинге:
- Подходит для размещения на GitHub Pages, Vercel, Netlify, Cloudflare Pages или любом стандартном веб-сервере (Nginx / Apache).
